Engineered for Performance

Built for Modern Windows Storage

Voltrex Light replaces sluggish legacy utilities with a modern 64-bit engine designed for today's terabyte SSDs and complex NTFS partition structures.

Non-Blocking Scan Engine

Multi-threaded asynchronous file system crawler with UI update throttling (~60 ms). The application never locks or stutters even while processing millions of nodes across NVMe drives.

Junction & Loop Avoidance

Detects NTFS reparse points, symbolic links, and volume mount junctions. Prevents infinite recursion cycles and eliminates inaccurate double-counting of physical drive storage.

Dual Interactive Visualizers

Seamlessly toggle between Filelight-style Radial Sunburst and Squarified Treemap charts. Features double-click drill-down, depth scaling (1-6 layers), and breadcrumb navigation.

Unified Storage Analysis

Multi-column sortable table showing exact bytes, % of Parent, % of Root, file counts, and modification stamps. Features instant in-memory filtering with Ctrl + F search.

Full Windows Shell Integration

Direct access to Explorer context menus: Show in Explorer, Open, Open With, Copy Path, Scan from here, Recycle Bin, and Permanent Delete with safeguards.

100% Private & Telemetry-Free

Operates entirely offline. No cloud accounts, no data tracking, and zero diagnostic telemetry. Your directory paths, filenames, and file sizes never leave your device.

Visualization Suite

Two Complementary Ways to Inspect Storage

Different disk cleanup tasks benefit from different visual models. Voltrex Light integrates both with instant one-click switching.

RADIAL SUNBURST

Concentric Hierarchy (Filelight Model)

The center disc represents the root folder, while concentric outer rings depict descending folder depths. Angular intervals maintain strict parent-child spatial containment.

  • Intuitive Depth: Immediate perception of deep folder trees versus shallow directories.
  • Fast Drill-Down: Double-click any arc to zoom in; click the center to navigate up.
  • Proportional Angles: Angle width directly corresponds to disk occupancy percentage.
SQUARIFIED TREEMAP

Space-Filling Rectangles (Bruls Algorithm)

Uses the Bruls, Huizing, and van Wijk layout algorithm to optimize rectangle aspect ratios close to 1:1, maximizing space efficiency and legible labels.

  • 100% Screen Utilization: Packs the entire container without wasted circular margins.
  • Direct Area Comparison: Compare disparate directories side-by-side by visual surface area.
  • Category Palette: Color-coded by directory type and sub-tree groupings.

Frequently Asked Questions

Answers & Troubleshooting

How does Voltrex Light compare to WinDirStat or TreeSize?
WinDirStat is an unmaintained C++ codebase from the 2000s that frequently freezes on multi-terabyte SSDs and cannot handle modern Windows 11 high-DPI scaling. TreeSize is proprietary commercial software. Voltrex Light is modern, open-source, written natively in C#/.NET 8 with WinUI 3, uses non-blocking asynchronous traversal, provides both Sunburst and Treemap visualizations, and has zero telemetry.
Why is there a "Run as Admin" button in the titlebar?
Under Windows User Account Control (UAC), standard applications cannot read metadata inside protected system folders such as C:\System Volume Information, C:\Windows\CSC, or system-owned directories. Clicking "Run as Admin" safely restarts Voltrex Light with elevated privileges so every byte on the drive is accurately cataloged.
Does Voltrex Light collect any user telemetry or analytics?
No. Voltrex Light does not collect telemetry, crash diagnostics, or user analytics. All file scanning is strictly performed locally in memory on your PC. The only network request occurs when you manually click "Check for updates" in Settings, which retrieves the public GitHub version.json manifest.
How do in-app software updates work?
Voltrex Light includes an update manager in the Settings page. When an update is detected, an interactive modal displays the release notes, downloads the verified installer directly from GitHub Releases with live progress reporting, and prompts you to launch the setup file.
What are the minimum system requirements?
Voltrex Light requires a 64-bit (x64) processor running Windows 11 (any version) or Windows 10 Version 2004 (Build 19041) or higher. All required Windows App SDK and .NET runtimes are bundled self-contained inside the executable.
